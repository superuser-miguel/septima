Septima is a GNOME app for 7-Zip ZS. Zstandard, Brotli and Fast-LZMA2 inside real .7z, every setting as a control instead of a switch you have to remember, and batch encryption with one password per archive.

  Batch encryption · since 0.5.0
  
One password per archive. One file to get them all back.

  

    Encrypt a pile of folders without inventing a password for each, or reusing one for all of them.
    Every archive gets its own random password, and Septima writes them all into a
    passwords file that you keep wherever you keep secrets.
  

  

    

      
1 · Pick what to encrypt

      
    
      
    
        
        
        
      
    
    
    
    
    
      
    
        The passwords file
        
    
          
          
        
    
      
    
      
    Press Encrypt to see the file Septima writes.
    
      
    These passwords are generated in your browser the same way the app does it, and never leave this page.
    
    
    
  
    
  
    
    
    Truly random, every time
    64 characters from the kernel's random source for each archive, with no bias toward any letter. Nobody has to think one up.
    
    
    A file, not a vault plug-in
    Plain JSON with each archive, what it was made from, its password and the cipher in words. Keep it in KeePassXC, Bitwarden, pass, or a drawer.
    
    
    Protect the file too
    Optionally lock it with a password of its own using standard gpg -c, so any gpg anywhere opens it. Chosen before the run, so a protected run never writes plaintext.
    
    
    Safe if it stops halfway
    Every password is on disk before the first archive is created, and the file is rewritten safely as each one finishes.

  Batches · reworked in 0.7
  
    Drop a hundred archives. Get one answer.
    
  
    
    
    
      
    Select or drop a pile of archives and each one unpacks into its own new folder. Septima stays quiet while it works, then tells you once how it went.
    
      
    
        Extracted 48 archives · 2 failedShow in Files
      
    
      
      
        
    • A few at a time. Septima works on half as many archives as your CPU has threads, at least 2 and at most 8. The rest wait their turn, and you can cancel one, or all of them, before they start.
      • 
        
    • Its own way in. Extract Several Archives is in the menu, on the start page and on Ctrl+Shift+E.
      • 
        
    • Problems collected, not interrupting. Anything that failed is listed in one dialog at the end, instead of a pop-up per archive.
      • 
        
    • One password question. Encrypted archives wait until the rest finish, then Septima asks once. A wrong password asks again; Cancel skips them.
      • 
        
    • Nothing replaced by surprise. If an archive's folder already holds files of the same name, Septima asks first: keep both, skip, or replace. Keep both is the default.
      • 
        
    • Works the other way too. Stage several files or folders and get a separate archive for each, saved right next to it.
      • 
      
    
    
    
    
    
      
    Same names never overwrite each other.
    
      
    
        
    
          
    In the batchBecomes
    
          
            
    photos.zip→photos/
    
            
    photos.7z→photos_2/
    
            
    report.txt→report.7z
    
            
    report.pdf→report_2.7z
    
              
        
    
      
    
      
      
        
    • Drag out to extract. Select rows in an open archive and drag them into Files. They arrive extracted, folders with everything inside.

  The rest of the toolkit
  
      Everything the command line can create.
      
  
      Septima covers what the bundled 7zz can make on Linux, as controls rather than switches.
      
  
      
    
      Tarballs in one step
      A real .tar.zst, .tar.xz, .tar.br, LZ4, LZ5 or Lizard tarball from one dialog, with full control of the compressor.
      
    
      Single-file streams
      Write a bare .zst, .br, .lz4, .lz5, .xz, .gz or .bz2.
      
    
      Filters as a menu
      ARM64, RISC-V, x86 BCJ/BCJ2, PowerPC, SPARC and Delta, picked from a list instead of learned as -m0= incantations.
      
    
      Checksums, 13 of them
      CRC, MD5, SHA-1/2/3, BLAKE3, BLAKE2sp and XXH, with copy and verify. Or write a .sha256 next to a new archive.
      
    
      Edit and test in place
      Delete or rename entries inside an archive, and check its integrity with one click.
      
    
      Presets
      Save a codec, level, dictionary and thread setup once, and reuse it on the next archive.
      
    
      Strong encryption choices
      AES-256 with optional encrypted file names for .7z, and AES-256 for zip instead of its weak ZipCrypto default. Since 0.7, .7z can also use XChaCha20-Poly1305 or one of three AES/XChaCha20 cascades, which open in 7-Zip ZS 26.05 or newer.
      
    
      Sandboxed
      A Flatpak that ships its own 7zz and reaches your files only through the desktop's file portals, never your whole home folder.
      
    
      An escape hatch
      The Advanced field passes any 7-Zip switch straight through, like -mfb=273 or -snl, for the cases a control doesn't cover.
      
  
      

      


      
  Roadmap
  
      Where Septima is going.
      
  
      Each step ships on its own. Fix releases keep the bundled 7-Zip ZS current in between.
      
  
        
    
      1. 
      
      
        Big batches, and more ciphers Live · 0.7
        
      
          
        
        • A cap on archives at once. A batch used to start every archive together. Now a few run and the rest wait, with a running and waiting count, Cancel All, and a job list that scrolls.
          • 
        
        • Extract Several Archives in the menu, on the start page and on Ctrl+Shift+E.
          • 
        
        • Four more encryption methods for .7z: XChaCha20-Poly1305 and three AES/XChaCha20 cascades. They open in 7-Zip ZS 26.05 or newer, not stock 7-Zip, and AES-256 stays the default.
          • 
        
        • Presets don't downgrade quietly. One that asks for a method this 7-Zip lacks says so.
          • 
      
        
    
        2. 
    
      2. 
      
      
        Keyboard, help, and no silent overwrites Live · 0.6
        
      
          
        
        • Extracting never replaces a file without asking. Before 0.6 it did, silently. Now Septima checks first and asks only on a clash: keep both, skip, or replace.
          • 
        
        • Keyboard shortcuts throughout, with the full list on Ctrl+?.
          • 
        
        • What Septima Can Do on F1, generated from the code so it can't drift from it.
          • 
        
        • An About window with release notes and the exact 7-Zip ZS build inside.
          • 
      
        
    
        3. 
    
      3. 
      
      
        7-Zip ZS 26.05 Live · 0.5.2
        
      
        Fixes a brotli decoder buffer overflow (CVE-2026-111497) and a use-after-free in single-file extraction, makes damaged archives report an error instead of extracting silently, and opens more brotli files without extra steps.
